Prerequisites and other install methods

  1. Install in your terminal

    Linux · macOS · WSL2
    curl -fsSL https://yapp.riggedcode.com/install.sh | sh

    The installer uses a private environment and downloads compatible Python if needed. Read the install script.

  2. Open yapp and create a session

    Run yapp. Name your session, then choose an orchestrator provider and an absolute project directory. This starts that provider.

  3. Add a worker and send a task

    Press F3 → Add agent. Pick a provider, name, and project directory. @mention the worker, or let your orchestrator route the request.

Before you start.

Need a hand? Check troubleshooting or open an issue.

How do Claude Code and Codex talk to each other?

Add both to a yapp session. Each connects to the same local MCP chat server, where it can read messages and @mention the other agent. You can follow the conversation and send your own instructions.

Is yapp free?

yapp is free and open source under the MIT license. Provider subscriptions, API usage, and any local model compute are separate.

Does everything stay on my machine?

yapp stores chat and session data locally and binds its server to localhost by default. Cloud coding agents still send prompts and relevant context to their providers under your existing account settings.

Can I use Windows or local models?

Use WSL2 for the full terminal workflow on Windows. Native Windows has browser chat and wrapper launchers, but terminal-session management requires tmux. OpenAI-compatible local models connect through the separately configured API wrapper; they are not terminal agents in the Add agent flow. Read the provider notes.

How does yapp update?

Package installations check for published releases while the TUI is open, with automatic installs enabled by default. Run yapp update --check to inspect availability or yapp update to update manually. Source checkouts use Git. See update controls.

What is the goon command?

goon is an alias for yapp. Both commands open the same application and accept the same arguments.
